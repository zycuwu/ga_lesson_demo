JavaScript × GA4 · 從「按下按鈕」到「記錄事件」

事件監聽器負責接收使用者動作，函式負責執行工作。也能在工作完成時呼叫 GA4：例如加入購物車成功後，記錄 add_to_cart。此處僅為本機模擬，不載入 Google 追蹤程式、不傳送資料。

function addToCart(album) {
  // 先更新購物車，再記錄成功的動作
  gtag("event", "add_to_cart", {
    currency: "TWD",
    value: album.price,
    items: [{ item_id: album.id,
      item_name: album.name,
      price: album.price, quantity: 1 }]
  });
}
btn.addEventListener("click", function () {
  addToCart(album);
});

瀏覽器事件 click 與分析事件 add_to_cart 是不同概念。真正上線需要建立 GA4 資源、安裝並設定 Google tag 與 Measurement ID，依適用規範處理同意，再於 DebugView 驗證。不要傳送姓名、Email 或留言內容；input 範例也不逐字送到 GA。
