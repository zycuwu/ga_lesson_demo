RECORD LAB｜網頁三劍客教室

開始使用
1. 解壓縮整個資料夾，請保留 covers、app.js 與 style.css。
2. 用 Chrome、Edge 或 Safari 開啟 index.html。
3. 頂端切換 HTML、+CSS、+JS 三階段。
4. 點「開啟元素探索」後，點選商店元素查看右側說明。關閉探索才能正常購物互動；探索點擊保持原位，只有從語法總覽選擇才定位。
5. 工具列的語法總覽可開啟浮動說明並定位元素；DOCTYPE、html、head 是文件設定，不是可見元件。
6. 原始碼下載 ZIP 提供三份獨立商店 HTML 與封面，可供學生修改。

教學流程（60 分鐘）
00–05 成品體驗；05–20 HTML；20–35 CSS；35–55 JS 與 GA4；55–60 複習。

範圍
虛構商店，無實際交易。留言不傳送或儲存；GA4 事件為本機模擬。
HTML / CSS 商店沒有 JS 功能；外部教學介面使用 JS 與 CSS 提供探索。

驗證狀態
已檢查語法、三階段分離、圖片路徑、購物車加總與移除、搜尋空狀態、表單攔截及事件模擬。已在 Chrome 離線開啟確認版面、探索浮動解說、input、add_to_cart 與 submit 事件紀錄。其他瀏覽器與手機未實機驗證。
